# On Windows install ONE ORT runtime wheel. Bakushi uses the NATIVE
# OpenVINO runtime (ov.Core) for both CPU and GPU separation, so the
# correct pairing is onnxruntime-openvino + openvino (exact match,
# official pairing: 1.24.1 <-> 2025.4.1). The ORT OpenVINO EP bridge is
# broken for this model, but onnxruntime-openvino still provides the
# ORT CPU EP fallback. Do NOT co-install onnxruntime-directml or plain
# onnxruntime - the wheels overwrite each other's provider DLLs.
onnxruntime-openvino==1.24.1
openvino==2025.4.1
